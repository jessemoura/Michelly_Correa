# Michelly Correa - Website Institucional

Este é o repositório do site institucional da comunicadora Michelly Correa.
O site é desenvolvido como uma Single Page Application (One Page) focada em apresentar seu portfólio, serviços de Mestre de Cerimônias, Campanhas Publicitárias e geração de contatos comerciais.

## Tecnologias
- HTML5
- CSS3 (Vanilla)
- JavaScript

## Idioma
O site é totalmente em Português do Brasil (pt-BR).
