# Brand Guidelines: Michelly Correa

This document contains the brand guidelines extracted from the provided mood boards and brand identity images.

## Brand Identity
- **Brand Name:** Michelly Correa
- **Niche/Subtitle:** Beauty - Nails - Lifestyle / Personal Brand
- **Monogram:** MC (Elegant interlocking 'M' and 'C')
- **Keywords/Essence:** Elegante, Moderna, Feminina, Atemporal, Exclusiva, Sofisticação, Beleza, Autoestima, Cuidado, Exclusividade.
- **Catchphrases:**
  - "Beleza nos Detalhes"
  - "Confiança se constrói com detalhes 🤍"
  - "Beauty Confidence Selfcare: Cuidado que transforma. Beleza que inspira."
  - "Be your best version. 🤍"

## Typography
- **Titles & Highlights:** **Playfair Display** (Serif)
- **Body Text & Support:** **Montserrat** (Sans-Serif)

## Color Palette

The brand utilizes an elegant, warm, and sophisticated palette. Below are the recommended hex codes based on the brand boards:

| Color Name | Hex Code | Meanings / Attributes |
| :--- | :--- | :--- |
| **Preto Elegante** | `#000000` / `#0A0A0A` | Elegância, Sofisticação, Força, Luxo |
| **Dourado Champagne** | `#D4AF37` / `#DAAF57` | Luxo, Beleza, Exclusividade, Prestígio |
| **Nude Sofisticado / Bege** | `#E8D9C6` / `#EAD9C6` | Feminilidade, Acolhimento, Naturalidade, Equilíbrio |
| **Rose Claro** | `#F7E9E1` | Delicadeza, Elegância, Suavidade |
| **Off White** | `#FAF9F7` / `#F8F5EF` | Pureza, Equilíbrio, Minimalismo, Leveza |
| **Taupe** | `#6B5E54` | Estilo, Modernidade |

## UI/UX Considerations
- Backgrounds should lean towards deep blacks (`#0A0A0A`) for high-contrast luxury sections, or Off White/Nude for clean, breathable sections.
- Gold (`#D4AF37` or gradients) should be used for accents, buttons, and important UI elements to convey luxury.
- Emphasize fine lines, generous whitespace, and elegant serif typography for headings to match the brand's premium feel.
